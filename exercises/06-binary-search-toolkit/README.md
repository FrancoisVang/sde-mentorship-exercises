# Exercise 06: Binary Search Toolkit

## Objective

Practice sorted data, boundary conditions, iteration, recursion, and reusable methods.

## Requirements

Implement methods for a sorted integer array to:

- Find the index of a target value.
- Find the first occurrence of a target with duplicates.
- Find the insertion position for a missing value.
- Return a documented result for an empty array.

Provide both iterative and recursive implementations for at least one operation.

Include tests for empty input, one element, duplicates, targets at both boundaries, and missing values.

## Submit

Include the implementation, tests, complexity analysis, and pull request.
