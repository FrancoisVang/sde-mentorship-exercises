# Exercise 03: Valid Parentheses

## Objective

Practice stacks, matching pairs, and input validation.

## Requirements

Given a string containing parentheses, brackets, and braces, determine whether the opening and closing characters are correctly matched and nested.

- Support `()`, `[]`, and `{}`.
- Return false for incorrect order, missing characters, or extra closing characters.
- Decide and document how non-bracket characters are handled.
- Include tests for empty input, nesting, mismatch, and incomplete input.

Examples:

- `"([]{})"` → true
- `"([)]"` → false

## Submit

Include the implementation, tests, approach explanation, complexity analysis, and pull request.
