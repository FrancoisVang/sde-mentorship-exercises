# Exercise 07: Linked List Utilities

## Objective

Practice nodes, references, pointer movement, mutation, and defensive edge-case handling.

## Requirements

Create a singly linked list and implement:

- Append a value.
- Insert at an index.
- Remove at an index.
- Reverse the list.
- Find the middle node.
- Detect whether a cycle exists.

Include tests for an empty list, one element, multiple elements, invalid indexes, and a cycle.

Document whether operations mutate the existing list or return a new list.

## Submit

Include the implementation, tests, design decisions, complexity analysis, and pull request.
