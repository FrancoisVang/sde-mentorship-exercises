# Exercise 05: Contact Manager

## Objective

Practice classes, encapsulation, collections, interfaces, validation, and clean design.

## Requirements

Build an in-memory contact manager that supports:

- Add a contact with name, email, and phone number.
- Update a contact.
- Delete a contact.
- Find a contact by ID.
- Search by name or email.
- List contacts sorted by name.
- Reject duplicate IDs and invalid required fields.
- Include unit tests for each operation and important failure cases.

Keep storage in memory. Do not build a user interface.

## Submit

Include a short design explanation, implementation, tests, and pull request.
