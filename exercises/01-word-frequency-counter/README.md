# Exercise 01: Word Frequency Counter

## Objective

Practice strings, maps, normalization, edge cases, and unit testing.

## Requirements

Build a `WordFrequencyCounter` that:

- Accepts a string.
- Treats uppercase and lowercase words as the same.
- Ignores punctuation.
- Returns a `Map<String, Integer>` containing each word and its count.
- Handles null or empty input according to a documented decision.
- Includes at least three JUnit tests.

Example:

Input: `"Java java, AWS!"`

Expected counts: `java=2, aws=1`

## Submit

Include the implementation, tests, a README with your approach and complexity, and a pull request using the repository workflow.
