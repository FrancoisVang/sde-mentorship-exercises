# Exercise 02: Two Sum

## Objective

Practice arrays, HashMap lookup, index handling, and complexity analysis.

## Requirements

Given an integer array and a target value, return the indices of two different elements whose values add to the target.

- Assume there is at most one valid answer.
- Do not use the same element twice.
- Document the behavior when no answer exists.
- Include tests for negative values, duplicates, and no solution.

Example:

Input: `[2, 7, 11, 15]`, target `9`

Expected result: indices `[0, 1]`

## Submit

Include the implementation, tests, approach explanation, complexity analysis, and pull request.
