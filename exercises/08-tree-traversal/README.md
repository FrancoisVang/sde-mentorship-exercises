# Exercise 08: Tree Traversal

## Objective

Practice binary-tree nodes, recursion, queues, and breadth-first traversal.

## Requirements

Given a binary tree, implement:

- Pre-order traversal.
- In-order traversal.
- Post-order traversal.
- Level-order traversal.
- A method that returns the tree height.

Include tests for an empty tree, a single node, a balanced tree, and an unbalanced tree.

Explain when recursion is useful and what the space complexity is for each traversal.

## Submit

Include the implementation, tests, traversal explanations, and pull request.
