# Exercise 09: Graph Navigator

## Objective

Practice adjacency lists, visited sets, breadth-first search, and shortest paths.

## Requirements

Represent an unweighted directed graph and implement:

- Add a directed edge.
- Return the neighbors of a node.
- Determine whether a path exists between two nodes.
- Return a shortest path as a list of nodes.
- Handle cycles and disconnected nodes.

Include tests for a direct path, multi-step path, cycle, disconnected graph, and missing node.

Document the time and space complexity of graph traversal.

## Submit

Include the implementation, tests, approach explanation, complexity analysis, and pull request.
