# Exercise 10: Task Tracker API

## Objective

Make the transition from algorithm exercises to backend development with Java and Spring Boot.

## Requirements

Build a small REST API for managing tasks.

A task should have an ID, title, description, status, priority, and timestamps.

The API should support:

- Create a task.
- Get a task by ID.
- List tasks.
- Update a task.
- Delete a task.
- Filter tasks by status.
- Validate required fields.
- Return appropriate HTTP status codes.
- Include controller/service/repository separation.
- Include unit tests and at least one integration test.

Start with an in-memory repository. Database persistence and AWS deployment will be added in a later project phase.

## Submit

Include setup instructions, API examples, design decisions, tests, and a pull request. Do not commit secrets or credentials.
